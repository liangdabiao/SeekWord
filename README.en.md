<p align="center"><em>Preview key vocabulary from any English content before you read or watch – then dive in with confidence and context.</em></p>

**SeekWord = Caption + Preparation.** It helps you learn languages efficiently by turning any English content into a targeted pre‑study session. Whether it's YouTube subtitles, a web article, a highlighted selection, or text you paste in, SeekWord previews key words & expressions first. Then read/watch the original; the built‑in context cements memory naturally. Contextual learning becomes lighter, faster, and more fun.

## 🤔 What can it do?
### 1｜Multi-source content capture
- **YouTube subtitles**: auto-captured with multi-path extraction & self-healing fallbacks.
- **Web articles**: click the extension icon or right-click "Learn this page" to auto-extract the article body.
- **Text selection**: select any text on a page and right-click to build cards from it.
- **Manual paste**: click "+" in the panel to create content from pasted text.

### 2｜Smart filtering & flashcard generation: AI does an initial sift; you fine‑tune the selection; flashcards are generated automatically—start studying instantly. Click the speaker icon on any card to hear the pronunciation.

## ⚙️ How to use
1. Install:
- Chrome Web Store: https://chromewebstore.google.com/detail/captiprep/jgbcfnmpjaflngdajjjnlehfkfohlmfl?authuser=0
- Edge Add-ons: https://microsoftedge.microsoft.com/addons/detail/captiprep/fbfhhgelelmeopkjdihhklkcncbikjem
- Dev (local): Chrome → `chrome://extensions` → enable Developer Mode → Load unpacked → select this repo (git clone https://github.com/liangdabiao/SeekWord.git first).

2. **Video**: open any YouTube video with subtitles and click the extension icon.
3. **Article**: open any English web page and click the extension icon, or right-click "Learn this page" to auto-extract the article body.
4. **Selection**: select some text on a page and right-click "Learn this page".
5. **Manual**: click "+" (New content) in the panel and paste text.
6. In the floating panel: extract content → select words/phrases → generate cards → study. **Arrow keys switch cards; Space favorites a word.**
7. Open the Wordbook to revisit learned items anytime; filter by source (Video/Article/Selection/Manual).
8. Export to download your collected words.
9. Model tips: set the filtering model to gemini-3.1-flash-lite and the card-generation model to gemini-3.5-flash (or gemini-3.8-flash) for a good speed/quality balance.

### 🤖 LLM Configuration Guide (How to Fill in the Base URL)

Configure your API key, Base URL and models on the **Options page** (right-click the extension icon → Options). Settings are stored locally in your browser. The provider dropdown supports **Gemini, OpenAI, Claude (Anthropic), OpenRouter, and OpenAI Compatible**. Switch to your provider and fill in the table below. **Models and endpoints change quickly — the table below was verified in September 2026; if any model is renamed or retired, trust the list that "List models" fetches for you.**

> **The Base URL must be the full chat endpoint** (not a website URL and not just a domain) — it should end with `/chat/completions`, `/messages` or `:generateContent`. After filling it in, click "List models" to auto-fetch the provider's current model names and just click to select.

| Provider | Dropdown choice | Get API key | Base URL to enter | Current models (2026-09) |
| --- | --- | --- | --- | --- |
| **Google Gemini** (recommended) | Gemini | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | **Leave blank** (auto-built from the model) | Filter: `gemini-3.1-flash-lite`; Cards: `gemini-3.5-flash` or `gemini-3.8-flash` (newest) |
| **OpenAI** | OpenAI | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) | `https://api.openai.com/v1/chat/completions` | `gpt-5.4-mini` (fast/cheap) / `gpt-5.4` / `gpt-5.5` / `gpt-5.6-luna` / `gpt-5.4-pro` |
| **Claude** | Anthropic | [console.anthropic.com](https://console.anthropic.com/) | `https://api.anthropic.com/v1/messages` | `claude-haiku-4-5` (fast) / `claude-sonnet-5` / `claude-opus-5` / `claude-fable-5` (flagship) |
| **OpenRouter** (one key, many models) | OpenRouter | [openrouter.ai/keys](https://openrouter.ai/keys) | `https://openrouter.ai/api/v1/chat/completions` | `deepseek/deepseek-v4-flash`, `google/gemini-3.5-flash`, `openai/gpt-5.4-mini`, ... |
| **DeepSeek** | OpenAI Compatible | [platform.deepseek.com](https://platform.deepseek.com/) | `https://api.deepseek.com/v1/chat/completions` | `deepseek-v4-flash` (fast/cheap) / `deepseek-v4-pro` (strong) / `deepseek-v4-flash-vision-exp` |
| **Qwen** | OpenAI Compatible | [bailian.console.aliyun.com](https://bailian.console.aliyun.com/) | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen3.8-flash` (fast) / `qwen3.7-plus` (balanced) / `qwen3.8-max` (flagship) |
| **Kimi** | OpenAI Compatible | [platform.moonshot.cn](https://platform.moonshot.cn/) | `https://api.moonshot.cn/v1/chat/completions` (global: `https://api.moonshot.ai/v1/chat/completions`) | `kimi-k3` (flagship) / `kimi-k2.7-code` |
| **Zhipu GLM** | OpenAI Compatible | [open.bigmodel.cn](https://open.bigmodel.cn/) | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-5.2` / `glm-5.1` / `glm-4.7-flash` (free & lightweight) |

**Key points:**
- Except for Gemini, you must enter the **full** Base URL (including the trailing endpoint path) from the table; a wrong value will break API calls.
- Choosing **OpenAI Compatible** lets you connect any OpenAI-compatible service — DeepSeek, Qwen, Kimi, Zhipu GLM, local Ollama, and more.
- After filling it in, click **"List models"** to auto-fetch the provider's current model names and pick one instead of typing — the fetched list is always the latest.
- Your API key is stored only in your local browser and is never uploaded.
## ❓ Why it works
- Pre‑exposure: you remove friction before reading/watching.
- Real context: examples come from the exact content—retention sticks.
- Accumulation: everything funnels into one Wordbook for spaced review.
